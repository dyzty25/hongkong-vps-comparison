## 二、三种BGP线路到底有什么区别

这是很多人买之前最纠结的问题。野草云在香港节点提供三种BGP宽带类型，理解它们的差异是选对套餐的前提。

**优质BGP宽带**——国内三网方向线路优化较好。中国电信回程走CMI，中国联通回程在CU/NTT/CMI之间均衡选路，中国移动回程走Level3，国际方向择优选路。实测国内平均Ping延迟约40-50ms，电信方向约30-50ms，联通方向约60-70ms，移动方向约70-80ms。适合主要面向中国大陆用户的业务。

**精品BGP宽带**——国内方向优化更激进。中国电信回程走CU，中国联通回程走CU，中国移动回程走CMI，国际方向择优选路。这种配置的特点是电信和联通都走CU线路，延迟相对更稳定，但带宽峰值通常比优质BGP略低。适合对国内访问稳定性要求高、但带宽需求不极致的场景。

**国际BGP宽带**——不含CMI、CU线路，纯国际方向择优选路。中国内地方向延迟较高（约100ms+），但面向东南亚、欧美等国际方向的访问表现更优。适合做跨境电商独立站、面向海外用户的服务等不需要国内优化的业务。

一个值得注意的细节：优质BGP和精品BGP所包含的CMI、CU中国内地路由仅承诺出口，入向无承诺。也就是说，从国内访问服务器（入向）的优化有限，但从服务器访问国内（出向）是有保障的。这一点对于做反向代理、CDN源站等场景需要特别留意。
